# /public

Files here are copied to the site root as-is.

| File | What to do |
| --- | --- |
| `resume.pdf` | **You must add this.** Export your resume as `resume.pdf` and drop it in this folder — the hero's resume button links to `/resume.pdf`, so without it that link 404s. |
| `og-cover.png` | Placeholder social card (1200x630). Replace it with your own; `og-cover.svg` is the editable source. |
| `favicon.svg` | Swap the monogram for your own mark if you like. |
| `robots.txt`, `sitemap.xml` | Replace `your-domain.example` with your real domain. |
